- 【判断】初始全局最多运行 3 个修改候选，其余排队；同一批注多选两个 Agent 占两个名额。翻译使用独立队列，不占修改名额。

- 先验证两端启动、事件读取、取消和权限请求，再确定各适配器采用 CLI 还是已有服务接口。不要将网页内部接口视为跨版本稳定承诺。
- 同一批注的所有候选从同一不可变论文快照开始，包含所需 `.tex`、`.bib`、图片与模板依赖。无 Git 的论文目录也能创建工作副本，不要求用户先建仓库。
- 每个候选拥有独立目录、会话、输出和编译目录；不接入指向正式正文的修改型 MCP 服务。
- 工作副本本身不构成权限隔离。实现前必须验证文件工具、Shell、符号链接及 MCP 的写入边界；若无法阻止写入主稿，该适配器只能生成结构化建议，不能宣称已安全支持自动编辑副本。
- 产出原始基线、修改补丁、可读候选、说明、引用依据和编译结果。跨文件改动完整显示，不能仅展示一句改写而隐藏参考文献或宏定义变化。

### 采纳、冲突与撤销

- 每篇论文只有一个采纳写入通道；Agent 可以并行产出，正式正文的写入有序执行。
- 使用基线摘要、源文片段和上下文定位，PDF 页码仅作辅助。
- 采纳前检查相关文件是否变化；仅在能证明无冲突时合并。同段重叠、模板或参考文献依赖冲突显示为需要重新比较，不盲目覆盖。
- 先对当前主稿加上候选的合并结果在临时目录编译，成功后再次检查基线，记录恢复信息并提交文件变更。多文件操作需要事务日志和失败恢复，不能将多个文件替换称为天然原子操作。
- 只有正文应用、正式编译及 PDF 更新成功后，才标记已采纳并解决批注；失败保留待处理状态。
- 撤销恢复该次采纳引入的变更，遇到后续重叠修改先提示冲突，不覆盖后来的工作。
- 主聊天或外部编辑器修改正文也必须触发版本更新和候选过期检查；与采纳同时发生时中止本次提交。

## 翻译服务

- 【判断】先提供可配置的服务接口，具体服务商和协议待确定。接口地址、服务类型、可选模型及连接测试位于应用设置；密钥由用户在应用中填写，采用系统安全存储，不进入仓库、日志或任务导出。
- 只发送本次需要翻译的段落和必要上下文，不默认发送整篇论文。显示当前服务和翻译语言。
- 优先从 PDF 文本层取得可见段落；多栏阅读顺序、断词、公式需要验证。不能可靠取得文本时提示改用划选；第一版不承诺扫描 PDF OCR。
- 滚动请求防抖，限制请求并发；旧响应不能替换新位置的译文。取消本地等待不等于服务端不会计费。
- 缓存键包含原文摘要、语言、服务、模型与翻译规则版本；正文变化只使相关内容缓存失效。
- 保留公式、引用编号与专名；译文清晰标识为阅读辅助，不修改 `.tex` 或自动新建批注。
- 支持关闭翻译、重试和错误提示；限流时退避，不无限重试。翻译失败不阻塞阅读或修改任务。

## 建议模块边界

在现有 Swift 应用中按职责拆分，名称为实施建议：

- `PaperWorkspace`：论文生命周期与服务连接，不再承担所有修改任务状态。
- `CommentBridge`：批注提交配置、事件、快照对账、阅读位置与选中文本。
- `TaskStore` / `TaskScheduler`：持久化、去重、排队、取消、重启恢复。
- `AgentAdapter`：启动、流式事件、权限等待、取消、候选收集；分别实现 Kimi 与 Codex。
- `SnapshotStore` / `ProposalApplier`：基线、独立工作目录、差异、合并、编译、恢复与撤销。
- `TaskListView` / `ProposalComparisonView`：任务进度和候选比较。
- `TranslationService` / `TranslationView`：服务配置、请求、缓存和译文显示。

优先使用现有事件接口；如需扩展 PDF 页面的批注框和可见段落事件，把扩展源码及上游版本约束纳入本仓库，不能只修改 `.runtime` 中的临时安装文件。

## 实施顺序与完成标准

### A. 接口验证与 Kimi 即时任务

先在虚构示例验证批注事件、模型绑定、后台权限处理、隔离和取消。随后实现 Kimi 多批注并行、任务列表、候选预览、采纳和撤销。

验收：连续提交 3 条批注后仍可阅读；候选在各自会话生成；采纳前主稿及正式批注状态不变；事件重复不导致重复任务；单个失败不阻塞其余任务。

### B. Codex 候选对比

为同一批注从相同基线启动 Kimi 与 Codex，统一显示差异与状态。

验收：采纳任一候选后只有该候选的改动进入正文；另一候选保留可查看，并根据新版本判断是否过期；同段冲突、跨文件改动和编译失败都有可见处理路径。

### C. 阅读翻译

完成可见文本桥接、可配置服务、缓存和译文栏，再连接用户选定的真实服务。

验收：滚动暂停后译文对应当前段落；快速滚动不乱序；重复阅读命中缓存；公式和引用编号保留；离线/限流不影响阅读；缺少 API 配置时显示设置入口，不能用演示文本冒充真实翻译。

### D. 日常使用验收

验证退出清理、重开任务恢复、等待授权、模型不可用、外部编辑冲突，以及原生窗口真实拖选和阅读位置保持。源码构建通过不等于这些用户操作已通过。

## 待定事项

- 翻译服务商、协议和模型；不得假定已有可用凭据。
- 滚动与划选哪一种是主要翻译入口，目前按滚动优先设计。
- 是否需要更细的逐句候选拼接；第一版暂不纳入。
- 具体并发上限根据本机运行情况及服务额度调节，3 为初始建议。
