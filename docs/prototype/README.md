## 打开

在仓库目录启动 `python3 -m http.server 8767 --bind 127.0.0.1 --directory docs/prototype`，访问 `http://127.0.0.1:8767`。刷新恢复初始示例状态。

## 已确认的设计要求

- 【转述】管理整个论文项目，包括章节、参考文献、图片、表格及其他资源；GitHub 同步展示完整文件范围。
- 【转述】默认审阅渲染后的论文效果，分别查看修改说明和模型实际回复，源码降为可选详情。
- 【转述】任务、建议版本、正式论文版本分开；支持已完成任务与手动归档。
- 【判断】采用可收起的窄导航、阅读/修改/版本/GitHub 主工作区，以及宽幅修改前后比较。用户尚未确认最终视觉设计。

## 尚未实现或验证

本轮是可点击的设计交付，不是 App 功能验收。论文页面是 HTML 示意排版，未接真实 PDF、翻译、模型、队列、持久化、Git 或文件系统；新任务的处理方式仅展示选项，不模拟真实并发/批量执行。参考文献、图片和表格均为虚构演示。正式版本需扩展完整文件类型策略与快照范围、预先编译隔离建议、映射真实任务及锚点、持久化归档状态，并回归原生窗口与协作保护。当前安装版的编译失败仍未在此轮修复。
