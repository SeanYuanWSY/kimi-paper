# Kimi Paper

构建后的应用位于仓库的 `dist/Kimi Paper.app`，双击即可打开。也可以自行复制到个人「应用程序」文件夹（`~/Applications/`）。构建脚本不会自动替换已经安装的版本。

这是本机使用的 macOS 应用，左侧保留 Kimi Code 官方网页界面，右侧显示论文。底层继续使用你已安装的 Kimi Code；应用内附带论文批注环境。

## 平时怎么用

1. 双击 Kimi Paper。首次打开示例论文，之后恢复上次的论文和对话。
2. 在右侧拖动选中文字，点弹出的 **Comment**，写下修改意见，再点 **Post**。也可以点 **+ Note** 给整篇论文留意见。
3. 点窗口顶部 **处理批注**。左侧会显示 Kimi 的思考、工具调用、确认请求和回复。
4. Kimi 修改、编译后，右侧 PDF 自动更新。检查结果，再继续批注。

也可以直接在左侧与 Kimi 交流。模型与能力仍由 Kimi Code 提供，原有搜索、Swarm、工具和 Skills 入口保留。首次新建对话会从已配置模型中选择 K3；可以在左侧调整。

## 打开自己的论文

点顶部 **打开论文**，选择 `main.tex` 等 LaTeX 主文件。有多个 `.tex` 文件时请选择真正的编译入口。

应用会在该论文目录添加自己的批注配置和项目 MCP 配置；已有 MCP 内容会保留，并在更新前生成权限为 0600 的备份。首次打开未信任的目录，会说明目录范围并询问是否允许 Kimi 处理。

现在支持本地 LaTeX 工程。只有 PDF 或 Word 文件时，不能直接按这套流程修改源稿。复杂模板需要本机已安装对应的 LaTeX 编译器与宏包；已有 tex-mcp-web 配置会沿用。

## 常用操作

- **更多 → 新对话**：在当前论文目录另开对话。
- **更多 → 刷新页面**：重新加载左右页面。
- **更多 → 重新连接**：重新启动本应用的两个本地服务，并恢复当前论文对话。
- **更多 → 在 Finder 中查看论文**：找到正文文件。
- 退出应用会停止它启动的服务。处理中退出会出现确认；论文与对话已保存的部分仍会保留。

本应用复用了 [Kimi Code](https://moonshotai.github.io/kimi-code/en/guides/web.html) 和 [tex-mcp-web](https://github.com/MiiKiyoshi/tex-mcp-web)，是为这台 Mac 制作的本地集成应用，非 Kimi 官方发布的独立产品。目前依赖这台 Mac 上已有的 Kimi Code 和 LaTeX 环境。
