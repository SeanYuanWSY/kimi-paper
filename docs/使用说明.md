# Kimi Paper 0.8 使用说明

## 日常只需要三个操作

1. 在左侧 Kimi 原生侧栏选择工作区并打开或新建会话。
2. 在左侧对话中做起草、结构调整、数据分析和整篇修改。
3. 顶部打开文档文件夹，点击右侧「文件」选择文档；划选文字并写下要求，把细节修改发送到当前会话。

顶部的「GitHub」用于查看论文项目状态、提交、拉取和推送。翻译、手动编译和重新连接位于「更多」菜单。

## Kimi 工作区与右侧论文彼此独立

应用不再提供额外的工作区选择器。左侧就是完整的原生 Kimi Web：

- 同一个目录可以新建多个会话，让多个 Agent 分别工作；
- 不同会话可以选择不同目录或不同层级；
- 一个会话可以选择包含 `paper/`、`data/`、`figures/` 和 `analysis/` 的上层研究目录；
- 模型、思考强度、权限提示、会话搜索与归档继续使用 Kimi 自己的界面。

右侧可以打开整个文档文件夹，在「文件」浮层中进入子目录或选择文件。PDF、Markdown、文本和图片可以直接预览，无需先有 LaTeX 主文件；打开 `.tex` 时使用论文编译阅读器。

Kimi 正在工作时仍可切换文档，左侧的进程、工作区和会话保持不变。发送批注的短暂交接与 Git 维护期间会暂停切换，防止批注或 Git 操作错用目录。下钻子文件夹不会改变顶部显示的 Git 根目录；要更换 Git 根，请点击顶部文件夹入口。

例如：

```text
my-research/                 ← 左侧某个 Kimi 会话可选择这里
├── paper/
│   ├── main.tex             ← 打开后显示编译 PDF
│   ├── references.bib
│   └── figures/
├── data/
└── analysis/
```

另一个 Kimi 会话也可以直接选择 `my-research/data/`，或选择完全不同的项目。右侧仍保持当前论文。

## 大修改与细节修改

左侧适合直接告诉 Kimi：“根据这些实验结果重写 Results”“检查整个项目并补一版初稿”。Kimi 修改的是该会话拥有权限访问的真实文件。

右侧适合细节修改：

1. 在 PDF、Markdown 或文本中划选原文；
2. 点击「修改这段」，输入要求并发送；
3. 应用核对当时的会话、文件位置和内容版本；
4. 文本批注明确指定源文件；独立 PDF 批注带有页码，要求 Kimi 先核对对应的可编辑源文件；
5. Kimi 结束后自动刷新文本，已绑定的 LaTeX 论文自动重新编译。

如果你在发送前切换了会话或文件已更新，旧请求会被拒绝，请重新划选。切换文档会关闭该文档未发送的浮窗。不同会话可以并行运行；同一会话的后续批注交给 Kimi 原生会话排队处理。

## 权限与版本边界

应用启动官方 Kimi Web，不附加自动允许或绕过权限的参数。Kimi 能读取或修改哪些位置，以左侧会话选择的目录和 Kimi 自己显示的权限模式为准。

编译失败时，右侧保留上一次成功的 PDF，并提示你回到左侧修复。直接修改的版本控制以论文自己的 Git 仓库为准；提交前可在 GitHub 面板查看完整文件范围。打开论文不会自动创建或改写 `.tex-mcp-web.yaml`。

## GitHub 协作

「GitHub」面板作用于顶部所选文件夹，面板标题下显示完整路径。即使文件夹里只有 Markdown，也可使用现有版本功能：

- 查看当前分支和完整改动；
- 选择文件暂存并提交；
- 拉取与推送；
- 新建或切换分支；
- 设置远端仓库。

执行 Git 操作时，应用先临时锁住左侧输入，确认所有 Kimi 会话空闲，再暂停本地 Kimi Web；操作完成后恢复原会话。应用不会自动强推、重写历史或替你解决冲突。

多人合作建议每个人使用自己的分支，通过 GitHub Pull Request 合并。提交前检查文件范围，避免上传 API 密钥、登录配置和大型原始数据。

## 翻译

右侧划选翻译使用独立 API，支持 `qwen-mt-flash`。译文只辅助阅读，不写进论文。「更多 → 翻译设置」可以开关翻译、修改接口和模型；密钥由 macOS 钥匙串保存。

原生 PDF/文本的浮窗会在滚动时保留，点击其他位置、关闭按钮或 Esc 后关闭。Markdown 显示基本标题、段落、列表；大于 500 KB 时显示源码以避免卡顿。

当前支持 PDF、Markdown、UTF-8 文本（含 bib/csv/json/yaml 等）、常见图片及 LaTeX 工程。文本上限 4 MB、PDF 64 MB、图片 20 MB 且最多 8000 万像素；较大文件及未支持格式可在 Finder 中打开。图片暂不支持文字划选，Word 内置编辑、扫描 PDF OCR 和 PDF 源工程恢复尚未提供。
